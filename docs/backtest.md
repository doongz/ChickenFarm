# 回测与算法

本文介绍 ChickenFarm 的定投（AIP, Automatic Investment Plan）回测方法、内置算法原理，以及如何解读输出的小提琴图。

> 这里实现的定投方法仅为一种“最简单的思路”，抛砖引玉，不构成投资建议。

## 核心思想

定投的最终收益对**起始日**非常敏感。如果只用“距今 N 天前的某一天”作为唯一起点，结果具有很强的偶然性。因此 ChickenFarm 不取单一结果，而是：

1. 在“距今 N 天前”的那一天附近取一个**起始日区间**；
2. 对区间内的每一个交易日分别模拟一次定投；
3. 得到多个收益样本，用**小提琴图（Violin Plot）**展示其概率分布。

## 回测流程

入口为 [StupidPlan.analysis_realtime](../src/module/backtest_mod.py)，对每只基金、每个周期执行：

1. **计算起始区间**：由 `cycle`（周期天数）与 `size`（区间大小）得到
   `(N 天前, N 天前 + size)`。
2. **边界修正**：
   - 若起始日早于基金发行日，则将区间修正为从发行日开始；
   - 若结束日晚于数据库中最新净值日，则结束日修正为最新数据日。
3. **遍历起始日**：对区间内每一天调用算法；非交易日抛出 `NonTradingError` 并跳过。
4. **计算收益**：分别模拟“每周固定一天定投”和“每日定投”，收集收益率样本。
5. **落库**：结果写入 `db_backtest.tbl_<code>`，随后由绘图模块读取。

## 周期与区间配置

在 [backtest_mod.py](../src/module/backtest_mod.py) 的 `AutomaticInvestmentPlan` 中定义，两个列表按位置一一对应：

```python
InvestmentCycles  = [30, 60, 90, 180, 365, 730]   # 投资周期（天）
StartIntervalSize = [10, 20, 30,  60,  60,  60]   # 各周期的起始区间大小
```

含义：例如周期 180 天对应起始区间 60 天，即在“约半年前”起的 60 个自然日内逐日取样，以获得足够多的样本来刻画分布。

## 内置算法：StupidAlgorithm

“愚蠢算法”是最朴素的策略：**每期投入固定金额**（默认每期 1000，见
[algorithm.py](../src/algorithm/algorithm.py) 中的 `self._amount = 1000`）。

### 数据准备（Algorithm.prepare_data）

- 校验 `start`、`end` 均为交易日（`DateTools.is_trade_day`，基于 chinesecalendar）；
- 从历史净值中截取 `[start, end)` 的区间作为买入数据 `buy_df`；
- 取 `end` 当天的累计净值作为卖出价格 `sell_price`。

### 每周定投（invest_weekly）

遍历区间内所有交易日，按当日是星期几（`date.weekday()`，0~4）分别累计：

- 买入份额：`份额 += 金额 / 当日累计净值(totvalue)`；
- 投入成本：`成本 += 金额`。

最终对周一至周五分别计算收益率，返回长度为 5 的列表：

```
收益率 = (卖出价 × 累计份额 - 成本) / 成本
```

### 每日定投（invest_daily）

在区间内每个交易日都投入固定金额，整体计算一个收益率；在结果表中以
`week = -1` 作为特殊标记。

## 如何扩展新算法

1. 在 [src/algorithm/](../src/algorithm/) 中新增一个类，继承 `Algorithm`，实现
   `invest_weekly`（可复用父类的 `prepare_data` 数据准备逻辑）。
2. 在 [backtest_mod.py](../src/module/backtest_mod.py) 中新增一个 Plan 类，继承
   `AutomaticInvestmentPlan`，在工厂方法 `create_algo` 中返回新算法实例。
3. 在 [transport_mod.py](../src/module/transport_mod.py) 的 `_upload_backtest_data`
   里把新 Plan 加入 `aip_plans` 列表即可参与回测。

## 小提琴图解读

绘图核心函数为
[export_aip_violin_plot_by_filed](../src/plot/aip_plot.py)，按**领域**分别出图：

- **每一行**：一只基金在各周期（30/60/90/180/365/730 天）的回测分析。
- **每一列**：同一周期下不同基金的结果，可横向比较**不同基金的定投收益**。
- **每个子图**：包含周一至周五（标记 1~5）以及“daily”（每日定投）共 6 把小提琴。
- **中间横线**：中位数；小提琴顶端/底端短横线为**极值**；图中还标出 25%/75% 分位线。
- **小提琴的宽窄**：表示概率密度 —— 越宽说明越多样本落在该收益率附近，即**最有可能获得的收益率**。

配色约定：

- `daily`（每日定投）小提琴为**金色**；
- 中位数收益最高的“最佳定投日”被标为**红色**（由 `get_best` 依据各小提琴中位数比较得出）。

据此可以回答两类问题：

1. **择日**：对某只基金，选择周内哪一天定投，历史上中位数收益更高、分布更优；
2. **选基**：在同一领域与周期下，哪只基金的定投收益分布整体更好。

## 局限与注意事项

- 回测基于历史净值，**历史表现不代表未来收益**。
- 结果对周期、起始区间大小及数据完整性敏感；基金成立时间较短时可用样本会减少。
- 计算未纳入买卖费率、申赎确认规则与实际到账延迟等细节，属于简化模型。
- 多进程回测对数据库连接数有要求，建议将 MySQL `max_connections` 调到 500 左右。
