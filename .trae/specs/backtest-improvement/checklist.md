# 验收清单 Checklist

## 第一批：核心正确性

- [x] 回测全程**不卖出**，结束时仍持有全部份额，按估值日 C 净值盯市。
- [x] 同一估值日 C 下，周一~周五 5 个分组的扣款笔数均为 N、**投入本金**均为 N×amount（实际买入成交价/买入成本组间不同，不作为相等项）。
- [x] 5 个分组使用的是**同样的 N 个完整交易周**（周一~周五均交易日），盯市时点同为 C。
- [x] 收益率按 FR-1 公式 `price_C*Σ(amount/price) / (N*amount) − 1` 计算，可手算复核。
- [x] `daily` 组在同样 N 个完整周内每个交易日买入（5N 笔），同样 C 日盯市。
- [x] 周期→N 映射生效（30→4、60→8、90→13、180→26、365→52、730→104）。
- [x] C 前不足 N 个完整周时按实际缩减并标注「样本不足」。
- [x] 不再出现魔法数 `999`（错误以异常或 None 表达）。
- [x] 按代码段自动识别 fund/etf（51/56/58、15/16 为 ETF），配置覆盖项生效。
- [x] ETF 通路每期固定 L 手（100 份整数手），份额固定、花费现金随价格浮动。
- [x] ETF 收益率按 FR-1B：`avg_cost=价格算术均值`、`profit_rate=price_C/avg_cost−1`，本金取实际累计花费（非 N×amount）。
- [x] ETF 组同样全程不卖出、同样 N 完整周与 C；daily 每次 L 手、共 5N 次。
- [x] 配对检验输出每对工作日的 median_diff、p、Holm 校正 p_adj、effect_size。
- [x] best day 仅在「对 ≥3 个工作日方向一致且 p_adj<0.05」时标红。
- [x] 不满足条件的子图**无红色**并显示「无显著周几差异」。
- [x] `profit_rate` 为 `DECIMAL(7,4)`，DDL 与 ORM 定义一致，强行情收益不溢出。

## 第二批：样本与稳健性

- [x] 估值日 C 按交易日等间隔（默认 5）采样，不再逐日产生高度重叠情景。
- [x] 输出各工作日 / daily 中位数的 bootstrap 95% 置信区间（图中黑色误差线）。
- [x] 使用多个估值日 C；best day 仅在 ≥60% 时间块一致时成立，否则不标红（不稳健）。

## 第三批：成本与口径

- [x] 收益计算扣除可配置单边成本：ETF 价差（尾盘）、佣金默认 0；场外申购费 = buy_rate × 折扣。
- [x] 基金用累计净值 nav、ETF 用前复权收盘价 adj_close 成交与盯市，图题注明口径。
- [x] 30/60 天短周期子图带「样本少、噪声大」提示。
