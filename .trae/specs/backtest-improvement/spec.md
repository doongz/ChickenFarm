# 定投回测改进 Spec

## 1. 背景与目标

当前定投回测（`StupidAlgorithm` + `AutomaticInvestmentPlan` + 小提琴图）的**收益计算公式正确**，但作为「周几定投更优」的决策依据存在方法论缺陷，导致图中标红的 best day 不具前瞻性。

本 spec 的目标：在不推翻现有框架的前提下，修正核心偏差，使回测结果**可对齐、可检验、对卖出时点稳健**，并让输出如实反映「周几差异是否显著」，而非强行选出一个最优日。

**非目标**：
- 不重写采集（天天基金 / xalpha）链路。
- 不做高频 / 盘中择时回测。
- 不新增复杂的智能定投策略（价值平均、均线偏离等本期不做）。

## 2. 现状与问题

| 编号 | 问题 | 影响 |
| :-- | :-- | :-- |
| P0-1 | 各星期分组买入/持有未对齐：当前 `invest_weekly` 在同一 `buy_df` 内按工作日归集却同一 end 卖出，不同工作日的首买时点与持有期限不同 | 收益差混入持有期限差，无法归因周几效应 |
| P0-2 | `get_best` 直接取 6 组中位数最大值标红，无显著性检验 | 多重比较 / 事后最优，噪声也会产生「最佳日」 |
| P1-1 | 起始区间每个自然日取样，序列高度重叠 | 有效样本量虚高，分布偏窄、高估显著性 |
| P1-2 | 所有 start 固定同一卖出日 | 结论绑定单一市场环境，不稳健 |
| P1-3 | 标的多为场内 ETF，却按基金累计净值成交 | 未计市价 / 价差 / 滑点，与实盘不符 |
| P2-1 | 公式零费率，未使用已采集的 `buy_rate` 等 | 高估收益 |
| P2-2 | 30/60 天每组仅约 4 次扣款，噪声极大；周期用自然日；`profit_rate DECIMAL(5,4)` 易溢出 | 短周期误导、口径不齐、写库风险 |

## 3. 功能需求

### FR-1 长期持有 + 统一估值日 + 固定 N 个完整周对齐（对应 P0-1）

> 本 FR 描述**场外基金通路：固定金额下单**。ETF（固定手数）规则见 FR-1B，两条通路共用窗口/估值日框架，但下单模型与成本口径不同。

**基本立场（用户确认）**：模拟长期持有，**不卖出**，回测结束时仍持有全部份额。周几好坏用「统一结束日 C 的净值对全部持仓盯市的市值 − 累计投入本金」衡量，而不是卖出兑现。

**两类「成本」的区分（重要）**：
- **投入本金（现金支出）**：每期固定 amount、共 N 期 → 5 组相同，均为 `N×amount`。
- **买入成本（实际成交价）**：不同工作日净值不同 → 组间不同，这正是周几效应的来源，不可混为「成本相同」。

- 每个情景以一个共同的**估值日 C**（交易日）结束；所有分组在 C 按当日 `totvalue` 盯市，`sell_price` 语义改为「盯市价格 mark_price」，不产生卖出交易。
- 周期用**买入笔数 N**（= 周数）表达，不再用自然日。买入窗口 = C 之前**最近 N 个「完整交易周」**。
  - 「完整交易周」= 周一至周五 5 个工作日全部为交易日；节假日导致任一工作日休市的整周剔除，保证 5 组在同一组周内都有买入、笔数严格相等。
- 星期分组 w（周一~周五）：在这 N 个完整周中，仅在每周的 w 当天买入，每组恰好 **N 笔**。

**三种等价衡量口径（同一 C 下排序完全一致）**：

```
# A. 盯市收益（主口径，用户指定）
profit_rate_w = price_C × shares_w / (N×amount) − 1

# B. 累计份额
shares_w = Σ_{i=1..N} amount / price_{w,i}        # 越大越好

# C. 平均买入成本（价格的调和均值）
avg_cost_w = N×amount / shares_w                  # 越低越好
```

- 等价性：同一 C 下 `price_C` 与 `N×amount` 为各组公共量，可约去，因此
  **平均买入成本最低 ⇒ 份额最多 ⇒ 盯市收益最大**。故「前期买得最便宜，最后收益也最大」成立。
- 口径选择：
  - B / C 不依赖最后一天价格，仅衡量「买得便宜」，实现与解读更简单，可作为交叉校验。
  - A 含资金时间效应，是主口径；当比较**投入节奏不同**的策略（如日定投 vs 周定投）时必须用 A，不能只比平均成本。
- 估值日 price_C 不改变周几组间排序（公共因子），只决定整体盈亏与波动幅度；真正需稳健性检验的是**不同 C 下排序是否稳定**。
- `daily` 基准：在同样的 N 个完整周内每个交易日买入（5N 笔），同样在 C 盯市；收益率口径相同，笔数不同不影响比率可比性。
- 周期映射（N = round(cycle/7)）：30→4、60→8、90→13、180→26、365→52、730→104；保留原 cycle 作为展示标签，内部按 N 个完整周取数。
- 数据不足（基金发行晚、C 前不足 N 个完整周）：按实际可用完整周数缩减 N，并对该情景标注「样本不足」，不与满 N 情景混用。
- 情景集合：C 在历史上按交易日等间隔采样（默认每 5 个交易日一个 C），每个 C 产出一组配对的周一~周五收益，同时支撑 FR-3（降重叠）与 FR-4（跨时点稳健）。

### FR-1A 标的类型识别：基金 / ETF（对应 P1-3 前置）

- 系统按 6 位代码段自动判定标的类型，无需额外维护字段：
  - **ETF（场内）**：`51xxxx`、`56xxxx`、`58xxxx`（沪市 510–519/56x/58x）与 `15xxxx`、`16xxxx`（深市 159 等）。
  - **基金（场外）**：其余代码。
- 判定结果用于选择下单模型（FR-1 固定金额 vs FR-1B 固定手数）与成交口径。
- 提供配置覆盖项（`backtest.fund_type_overrides: {code: fund|etf}`），处理分类基金/LOF 等边界情况；默认按代码段。

### FR-1B ETF 通路：固定手数下单 + 不卖出盯市

**下单模型（与基金方向相反）**：ETF 按「手」申报，1 手 = 100 份，只能买整数手。每期固定买入手数 L（默认 L=1，可配置），花费现金由成交价决定。

- 第 i 期买入：`lots_i = L`，`shares_i = L × 100`，`cash_i = L × 100 × price_i`。
  - 每期总份额相同（固定 L×100）；**投入本金随价格浮动**，这是与基金通路（金额固定、份额浮动）的根本区别。
- 周分组 w 在同样 N 个完整交易周内、每周 w 当天买入 N 次：

```
# 固定手数口径
total_shares_w = N × L × 100
total_cost_w   = Σ_{i=1..N} L × 100 × price_{w,i}
avg_cost_w     = total_cost_w / total_shares_w          # = 价格的算术均值，越低越好
profit_rate_w  = price_C × total_shares_w / total_cost_w − 1
               = price_C / avg_cost_w − 1
```

- 因为没有零头、不预留现金，终值即 `price_C × total_shares_w`；本金是实际累计花费（各组不同），不能再用 `N×amount` 公共分母。
- **结论**：对固定手数 ETF，「平均买入价（算术均值）越低 ⇒ 盯市收益越大」依然成立，但平均成本是**算术均值**（基金固定金额时是调和均值），三口径中的「份额越多」不再有区分度（份额固定）。
- `daily` 基准：同样 N 个完整周内每个交易日买入（5N 次，每次 L 手），C 日盯市；跨节奏比较必须用盯市收益率。
- 成交口径：ETF 应用成交价而非基金净值；本期先按可用价格（默认 `nav`）跑通流程，`price_type(nav/close)` 参数与日线接入沿用 FR-5，接入后用 `close`。
- 窗口、完整周、C 采样、数据不足处理与 FR-1 完全一致。

### FR-2 显著性检验与 best day 标注（对应 P0-2）
- 对每一对工作日分组，基于「同一 start 情景」计算配对收益差，并做配对检验（默认 Wilcoxon 符号秩检验；样本量满足时可附配对 t 检验）。
- 输出：每对的差值中位数、效应量、p 值（经多重比较校正，默认 Holm 法）。
- 标注规则：
  - 仅当某工作日相对其余多数（≥3 个）工作日**差异方向一致且校正后 p < 0.05** 时，才标记为 best day（红色）。
  - 否则该子图**不标红**，并标注「无显著周几差异」。
- 原始中位数仍展示，但不再用裸 `max` 决定颜色。

### FR-3 降低样本重叠（对应 P1-1）
- 情景按**估值日 C** 在交易日上等间隔采样（默认每 5 个交易日一个 C，与 FR-1 一致），替代当前「起始区间每个自然日」的高度重叠取样。
- 提供基于情景的 bootstrap 置信区间（默认 1000 次重采样）用于中位数误差线。

### FR-4 估值时点稳健性（对应 P1-2）
- 天然由 FR-1 的「多个估值日 C」实现：每个 C 是一个盯市时点，覆盖不同市场环境。
- best day 必须在**多数 C** 下结论一致，否则标记为「不稳定」。

### FR-5（可选，默认本期实现最小版）ETF 成交口径
- 至少在收益计算中**预留成交价类型参数**（`nav` / `close`）与**单边成本参数**（费率 / 价差 / 滑点）。
- 若本期不接入 ETF 日线数据源，则默认 `nav` 且成本可配置（默认 0），并在图标题注明口径；接入数据源列为后续任务。

### FR-6 费率与字段健壮性（对应 P2-1 / P2-2）
- 申赎/交易成本作为参数参与收益计算，可从已采集 `buy_rate` 读取或由配置覆盖。
- `profit_rate` 库表字段扩容至 `DECIMAL(7,4)`（DDL 同步）。
- 周期统一用**交易日**口径或在输出中明确标注自然日；30/60 天子图自动加注「样本少、噪声大」。

## 4. 输出与兼容性要求

- 保持现有「每基金一行 × 每周期一列」的小提琴图布局与导出路径不变。
- 新增统计结果（p 值、效应量、置信区间、稳健性结论）需可落库或导出为随图附带的 CSV / JSON（默认导出到 `EXPORT_AIP_PLOT_PATH` 同级 `stats/` 目录）。
- 保留 `stupid` 算法名与现有表结构，新增字段只能追加，不破坏已有读取逻辑。
- 改动应可通过开关回退到旧行为（配置项 `backtest.align_window`、`significance_test` 等，默认开启新行为）。

## 5. 验收标准（摘要，详见 checklist.md）

- 同一估值日 C 下，5 个工作日分组的扣款笔数（N）、投入成本、买入窗口（N 个完整周）与盯市时点完全一致，且回测全程不卖出、结束时仍持有全部份额。
- 收益以 C 日净值对全部持仓盯市的市值减成本计算，公式见 FR-1。
- 图中红色 best day 仅在统计显著且跨估值日 C 稳健时出现，否则明确标注无显著差异。
- 报告含配对检验 p 值、效应量、bootstrap 置信区间，并可导出。
- 短周期子图有噪声提示；强行情收益不再因字段精度溢出。
- 全流程（净值→回测→绘图）对现有 17 只基金可跑通。

## 6. 范围取舍（实施顺序）

1. **第一批（必须）**：FR-1（基金固定金额通路）+ FR-1A（类型识别）+ FR-2 + FR-6 字段扩容。先把基金通路调通并验证。
2. **第二批（紧接着，用户主要持仓为 ETF）**：FR-1B（ETF 固定手数通路），复用第一批的窗口/估值日/统计框架；ETF 成交先用 `nav`，`close` 日线接入随 FR-5。
3. **第三批（建议）**：FR-3、FR-4。
4. **第四批（可选）**：FR-5 的 ETF 日线 `close` 接入（本 spec 已落地参数预留）。
